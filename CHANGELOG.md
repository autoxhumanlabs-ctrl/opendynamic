# Changelog

Each version gets a GitHub release with a ready-to-run download. To ship a new version: add a `## vX.Y.Z` section at the top of this list, commit it, then push a tag with the same name (`git tag vX.Y.Z` then `git push origin vX.Y.Z`).

## v1.0.1

- **New icon:** the OpenDynamic dragon logo, a Japanese dragon coiled around the island. It shows on the app, its shortcuts and the taskbar.
- **Clearer Liquid Glass by default:** less frost and less darkness, so you can see what's behind the card.

## v1.0.0

First public release.

- **Music:** cover art, title and controls for any app in Windows' media controls (Spotify, YouTube, Netflix…), with shuffle, repeat and wheel-to-change-volume.
- **Live visualizer:** WASAPI loopback audio split into bass and vocals. Big bass swells on every kick, a flowing vocal wave, and a beat ring on the collapsed notch.
- **Notch:** click-through when collapsed, tucks away when the cursor comes near, and opens when you push the cursor to the top edge. Curved shoulders flow out of the screen edge, and there's a floating-pill option. It hides in fullscreen video and games.
- **Liquid Glass:** a see-through frosted card with lens refraction, prism edges, bass ripple and a cursor-following shine. All of it is adjustable, plus an optional aurora background.
- **Clipboard:** your last 20 copies, kept in memory only. Password-manager copies are skipped.
- **Links:** YouTube, Netflix and TradingView tiles, editable in `links.txt`.
- **Markets:** gold, silver and NAS100 futures with sparklines; click a card for the TradingView chart.
- **Settings:** wave strength, beat sensitivity, colour palettes, battery saver, synced lyrics and start with Windows.
